# Provider workflow catalog

Load only the workflow relevant to the current request.

- [postiz-audience-analytics](../../postiz-audience-analytics/WORKFLOW.md): Read channel and per-post engagement analytics via the postiz-agent MCP server and land them in the knowledge graph as time-series engagement — impressions, likes, follower trends over a date window. Use when the agent must report on how content or a channel is performing, or backfill engagement history into the KG. Do NOT use for creating/scheduling posts (use postiz-content-scheduling) or managing accounts (use postiz-channel-management).
- [postiz-channel-management](../../postiz-channel-management/WORKFLOW.md): List, connect, and remove social channels (integrations) via the postiz-agent MCP server, and land them in the knowledge graph as :SocialChannel nodes — enumerate connected accounts, get a provider OAuth connect URL, check connectivity, delete a channel. Use when the agent must inspect or manage which social accounts Postiz can publish to. Do NOT use for creating posts (use postiz-content-scheduling) or reading engagement (use postiz-audience-analytics).
- [postiz-content-scheduling](../../postiz-content-scheduling/WORKFLOW.md): Schedule, publish, and manage social posts across connected channels via the postiz-agent MCP server — list a date window of posts, create a draft/scheduled/now post, attach uploaded media, find the next open slot, and delete posts. Use when the agent must plan or push social content through Postiz. Do NOT use for reading engagement numbers (use postiz-audience-analytics) or connecting/removing accounts (use postiz-channel-management).
